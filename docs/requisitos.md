# Requisitos originales

> Copia literal del encargo (fuente: `Requisites.txt`).

Construye un pequeño equipo de 3 agentes de IA que trabajen juntos:

1. **Orquestador**: recibe una petición (por ejemplo «añade una página de contacto a esta web»), la divide en tareas y se las reparte a los otros dos.
2. **Develop**: hace las tareas de desarrollo.
3. **Testing**: comprueba lo que ha hecho Develop y devuelve lo que falla, hasta que todo pasa.

## Requisitos

- Hecho en Next.js.
- Programado con Claude Code o con Codex (cuéntanos cómo los usaste).
- Con una base de datos gratuita (la que prefieras: Supabase, Neon, Turso, Firebase…).
- Publicado en Vercel, con una dirección que podamos abrir.
- Que en pantalla se vea qué hace cada agente y en qué estado está cada tarea.

No hace falta gastar dinero: usa planes gratuitos. No subas claves de API al repositorio.

## Entregables

- Dirección de la app desplegada.
- Repositorio de GitHub (público o con acceso para ellos).
- Usuario y contraseña de prueba si hacen falta.
- Respuestas a 4 preguntas cortas.
